# 商品データの定期更新ルーティン

目的：公式サイトで販売終了した商品や、古い価格がサイトに残らないようにする。頻度は2週間〜1か月に1回。

## 1回の流れ
1. `npm run sync:check` … 公式サイトを読み、変更点だけを表示（ファイルは変えない）
2. `npm run sync` … `data/products.csv` と商品写真を更新し、報告書を `docs/catalog-updates/日付.md` に保存
3. 変更をコミットして GitHub に保存 → Netlify が自動で公開サイトを更新
4. 報告書の内容（追加・価格変更・非公開にした商品）を妹尾さんに共有

## 更新のルール
- 公式サイトにある商品：価格・名前・容量・説明・使い方・成分・写真を最新に。「公開」「ラベル」はサロンの設定を残す
- 新しく見つかった商品：追加して公開（ラベル「NEW」）
- 公式サイトから消えた商品、「メーカー在庫終了」の商品：非公開にする（行は残すので、注文履歴とのつながりは切れない）
- 公式URLが空の行（サロンが手で追加した商品）：変更しない
- 読み取れた件数が極端に少ないとき（サイトのつくりが変わったときなど）は、更新せずに止まる

## 自動化
Claude の「スケジュールされたタスク」で、上の1〜3を定期的に実行し、報告書をまとめる設定ができます（GitHub への保存先が整ってから設定）。
