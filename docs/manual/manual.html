注文が来たら

05

サロンのメールに「【新規注文】○○様 ¥○○」が届いたら、決済は完了しています。受け取り方法を見て、どちらかの手順で進めます。

郵送の注文

  1. 注文メールで商品・個数・お届け先を確認
  2. 梱包して発送（伝票の宛先は「注文一覧」からコピー）
  3. 「注文一覧」でその注文の行をクリック
  4. メニュー「salon ito」→「発送済み／ご用意完了にしてメールを送る」
  5. 配送会社と追跡番号を入れて OK → お客様に発送完了メール

サロンで受け取りの注文

  1. 注文メールで商品・個数を確認
  2. 商品を用意し、名前を書いて取り置き
  3. 「注文一覧」でその注文の行をクリック → 同じメニューを押す
  4. お客様に「ご用意ができました」メールが届く
  5. 来店時に注文番号を確認してお渡し → メニュー「受け渡し済みにする」
コンビニ払い
入金されるまでメールは来ません。メールが来た注文だけ対応すれば大丈夫です。3日以内に入金がなければ自動でキャンセルされます。
キャンセル・返金
Stripe の「支払い」でお客様を探し「返金」。シートのステータスを「返金済み」に書き換えます。不良品は交換で対応すると手数料がかかりません。

初めてメニューを使うときだけ、Google の「承認が必要です」画面が出ます。サロンのアカウントを選んで許可してください。

GitHub とは

07

GitHub は、サイトの「設計図」を保管し、変更の履歴をすべて残しておく場所です。妹尾さんがふだん操作する必要はありません。

身近なものに例えると

GitHub の言葉例えるとsalon ito での意味
リポジトリサロンの「設計図ファイル棚」サイトのデザイン・画面・決済のしくみが全部入った保管場所（非公開）
コミットカルテに書く「施術記録」1回分「受け取り方法を追加」など、変更1回ごとの記録。日時と内容が残る
履歴を戻す以前のカルテを見て元のメニューに戻す不具合が出ても、前の正常な状態にすぐ戻せる
Netlify との連携棚に新しい設計図が入ると、店舗が自動で改装される設計図が更新されると、数分で公開サイトに反映される

できること・妹尾さんに関係あること

GitHub でできること

・変更の履歴を全部残す（誰が・いつ・何を）
・問題が起きたら前の状態に戻す
・管理者が交代しても設計図ごと引き継げる
・非公開なので、許可した人しか見られない

妹尾さんがやること

・基本的にはありません
・商品や価格の変更はスプレッドシートで完結します
・将来、管理を自分で持つと決めたら、サロンのアカウントへ「移管」するだけで引き継げます

GitHub（ギットハブ）は世界中の開発者が使うサービスで、非公開の保管場所は無料で使えます。

お金の流れと会計

09

売上は Stripe が手数料を差し引いて妹尾さんの口座へ自動で入金し、マネーフォワードに明細が取り込まれます。

マネーフォワードとの連携（最初に1回だけ）

  1. マネーフォワード クラウド会計 →「データ連携」→「新規登録」
  2. 「Stripe」を検索して選び、Stripe にログインして連携を許可
  3. 仕訳ルールを登録（下の表）。以後は取り込まれた明細を確認して登録するだけ
明細勘定科目の例
オンラインストアの売上売上高（補助科目：オンライン）
Stripe の決済手数料支払手数料
銀行口座への入金普通預金（相手は Stripe の残高）

画面の名称は変わることがあります。勘定科目は税理士さんの指示を優先してください。店頭の Airペイの売上は、これまでどおり別に管理します。

毎月の確認（10分）

  • 「月別集計」シートで先月の注文件数と売上を見る
  • Stripe の入金額とシートの「入金見込み」が大きくずれていないか確かめる
  • マネーフォワードに取り込まれた明細を登録する

ドメインの取得

10

おすすめは「salon-ito.jp」です。日本のサロンだと一目で分かり、QRコードやショップカードにも載せやすい名前です。

候補特徴年額の目安
salon-ito.jp（第1候補）日本に住所がある人・会社だけが取れる「.jp」。信頼感があり、名前どおりで覚えやすい3,000〜5,000円
salonito.jpハイフンなし。口頭で伝えやすい。「サロニト」と読まれる可能性あり3,000〜5,000円
salon-ito.com世界共通で安い。.jp が取れなかったときの候補1,500〜2,500円
ito-salon.jp上がすべて使われていた場合の予備3,000〜5,000円

空いているかどうかは、取得サービスの検索窓で確認します（この資料の作成時点では未確認）。料金は初年度の割引と2年目以降の更新料が違うので、更新料で比べてください。

取得からサイトにつながるまで

取得サービスの例

ムームードメイン、お名前.com、Xserverドメイン など。妹尾さんの名義・クレジットカードで取得し、自動更新をオンにします（失効するとサイトが表示されなくなります）。

あわせて検討

shop@salon-ito.jp のような独自アドレスでメールを送るには、別途メールサービス（Google Workspace など・月額制）が必要です。最初は今の Gmail のままでも運用できます。

困ったとき・チェックリスト

11
こんなときまず確かめること
「確認メールが届かない」と言われた「注文一覧」にあれば注文は成立。迷惑メールフォルダを見てもらい、注文番号を伝える
「支払ったのに注文できていない」Stripe の「支払い」にあるか。あってシートに無ければ管理者へ
商品を変えたのにサイトが変わらない5分待ってもう一度「サイトに反映する」。スマホは再読み込み
商品画像が出ないドライブの共有が「リンクを知っている全員」になっているか
在庫がなくなった「売り切れ」にチェック →「サイトに反映する」
不審な注文（同じ人が大量・住所が不自然）発送前に Stripe でその支払いのリスク評価を確認。心配なら返金して発送しない

管理者へ連絡するときは「注文番号（ITO-…）・お客様名・いつ何をしたらどうなったか・画面のスクリーンショット（住所や電話番号は隠す）」を添えてください。
