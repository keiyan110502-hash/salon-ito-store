# 公開準備ガイド（決済・法対応・チェックリスト）

日数や手数料は一般的な目安です。申し込みの時点で、各社の公式ページで必ず確認してください。

## 1. 決済：Airペイと Stripe の使い分け

| | Airペイ（今お使いのもの） | Stripe（オンラインストア用） |
|---|---|---|
| 主な用途 | 店頭での対面決済 | サイトのカートと一体になったネット決済 |
| オンライン | 決済リンクを作って送る機能（2025年3月〜）はありますが、カートと自動でつながる形ではありません | カートの金額がそのまま決済画面に渡り、支払いが終わると自動で記録とメール送信まで進みます |
| 結論 | 店頭ではそのまま使い続けます | オンラインストアは Stripe を使います |

### Stripe の申し込みの流れ（目安）
1. **アカウント作成**（当日・数分）：stripe.com/jp からメールアドレスで登録します。テストモードはすぐに使えます。
2. **本番利用の申請**（入力は30分ほど、審査は数日が目安）：「アカウントを有効化」から、次の情報を入力します。
   - 事業形態（個人事業主か法人か）
   - 代表者の本人確認書類
   - 事業内容（化粧品の小売）
   - サイトの URL
   - 入金先の銀行口座
   - 明細に表示する名称（例：SALON ITO）

   審査では、サイトに**特定商取引法に基づく表記・返品ポリシー・商品と価格が載っているか**を見られます。そのため、**先にサイトを Netlify で公開してから申請する**のがスムーズです。
3. **支払い方法の追加**（「設定 > 決済手段」）
   - カード・Apple Pay・Google Pay：本番有効化と同時に使えるのが一般的です。
   - コンビニ払い：ダッシュボードで ON にします。審査がある場合があります。
   - PayPay：ダッシュボードから別途申し込みます。PayPay 側の審査があり、数日〜数週間かかることがあります。PayPay が通るまでは、ほかの支払い方法で先に公開できます。
4. **入金**：売上は手数料を差し引いて、登録した銀行口座に自動で振り込まれます。入金のスケジュールはダッシュボードで確認・変更できます。
5. **会計との連携**：freee やマネーフォワード クラウドには Stripe 連携があります。売上・手数料・入金を自動で取り込めます。店頭の Airペイの売上と合わせて、会計ソフトで管理する形がおすすめです。

**手数料の目安**：国内カードは 3.6%（初期費用・月額費用なし）。PayPay とコンビニ払いの料率は、Stripe の料金ページで確認してください。GAS の `FEE_RATES` も、確認した料率に更新します（スプレッドシートの「入金見込み」の計算に使います）。

**後払い（Paidy など）について**：Stripe は後払いに対応していません。必要になったら、KOMOJU などの別の決済会社を追加する形で第2段階として検討します。まずは上の4種類で始めるのが、最も手続きが少ない進め方です。

## 2. 特定商取引法に基づく表記

ひな形はサイトに組み込み済みです（`#tokushoho`）。`public/data/shop.json` の `legal` 欄で【要入力】になっている箇所を埋めてください。

- **販売業者・運営統括責任者・所在地・電話番号**：個人事業主の場合も原則として記載が必要です。
  - 住所や電話番号の公開を避けたい場合は、「請求があれば遅滞なく開示します」と書く方法が認められる場合があります。ただし、Stripe の審査では連絡先の掲載を求められることが多いので、店舗の住所と電話番号を載せるのが無難です。
- **返品・交換**：ひな形は「お客様都合の返品不可、不良品は到着後7日以内に連絡」としています。サロンの方針に合わせて修正してください。
- **最終確認画面**：「ご注文内容の確認」画面に、分量・価格・支払時期と方法・引渡時期・キャンセル条件を表示しています。2022年の法改正で、最終確認画面への表示が義務になった事項です。

## 3. プライバシーポリシー

ひな形はサイトに組み込み済みです（`#privacy`）。【要入力】と制定日を埋めてください。

決済の Stripe（米国の事業者）とデータを保管する Google に情報を預ける旨を、「業務の委託」と「外国にある事業者」の項目に書いています。メールマガジンなどを始める場合は、利用目的を追記してください。

## 4. 薬機法と、メーカーとの取り決め

- **販売の許可**：化粧品や医薬部外品を仕入れて販売する（小売する）だけなら、販売業の許可は不要です。
- **広告表現**：サイト上の表現は、販売店にも責任があります（薬機法66条などの広告規制は「何人も」が対象です）。
  - **メーカー公式の説明文をそのまま掲載する方針は安全です。** 独自のキャッチコピーやお客様の声を足すときに、効果・効能の範囲を超えないよう注意してください。
  - NG になりやすい表現の例：「シミが消える」「アトピーが治る」「発毛」「医師も推奨」「〇日で効果」
  - 医薬部外品は、承認された効能の表現だけが使えます。公式の文章を変えずに使ってください。
- **⚠ 公開前に必ず確認してほしいこと（最重要）**
  - アジュバンもバイオラブも、サロン専売のブランドです。メーカーによっては、**取扱店が自社のネットショップで販売することを制限している場合があります。** 調べたところ、次のような情報が見つかりました。
    - アジュバン：サロン向けの公式オンラインストア「ADJUVANT LINK」があります。
    - バイオラブ：自社では通販を行っていない、との記載があります。
  - 取引のある代理店・メーカーに、次の点を確認してください。
    - 自社 EC での販売が可能か
    - 販売価格の指定があるか
    - 商品画像と説明文の転載が許可されるか
- **画像と文章の転載**：公式サイトやカタログの写真・文章は、許可を得てから使用してください。素材データとして正式に提供されたものであれば問題ありません。

## 5. 公開前チェックリスト

- [ ] メーカー・代理店からネット販売の許可を得た（画像・説明文の転載許可も含む）
- [ ] 全商品の名称・容量・価格を公式情報で確認し、`draft` を FALSE にした
- [ ] 商品説明・使い方・全成分を公式の文章で入れた
- [ ] 商品画像を正方形で用意した
- [ ] `shop.json` の【要入力】を全部埋めた（特商法表記・プライバシーポリシーの制定日）
- [ ] 送料と送料無料ラインを決めた（現在の仮設定：¥770、¥11,000 以上で無料）
- [ ] Stripe のテストモードで、カードとコンビニ払いを最後まで試した
- [ ] スプレッドシートに記録されること、お客様とサロンの両方にメールが届くことを確認した
- [ ] Stripe の本番審査が通り、本番キーと本番 Webhook に切り替えた
- [ ] 独自ドメインを設定した（任意）／QR コードを作った
